GODORAMA ANDROID - PROJETO INICIAL

O que é:
Projeto Android Studio simples que abre https://godorama.com/ em um WebView, com JavaScript, armazenamento local e suporte a vídeo HTML5 habilitados.

Como gerar o APK:
1. Instale o Android Studio em um computador.
2. Extraia este ZIP.
3. No Android Studio, escolha Open e selecione a pasta GodoramaAndroid.
4. Aguarde a sincronização do Gradle e instale os componentes Android solicitados.
5. Vá em Build > Build Bundle(s) / APK(s) > Build APK(s).
6. O APK de depuração normalmente ficará em app/build/outputs/apk/debug/app-debug.apk.

Observações:
- Este ZIP é o código-fonte do projeto, não um APK já compilado.
- O funcionamento de login, reprodução e downloads depende das regras do próprio site e de seus provedores de vídeo.
- O projeto usa o nome Godorama; use a marca e o conteúdo somente com autorização adequada.
- Antes de publicar na Play Store, configure ícone, política de privacidade, classificação etária, assinatura e teste em aparelhos reais.
- Para Android TV, será necessário adaptar a navegação para controle remoto e validar a compatibilidade.
